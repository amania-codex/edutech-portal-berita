# EduTech.id — Portal Berita Ramai

Prototype landing page portal berita pendidikan dan teknologi dengan layout editorial padat seperti portal berita sungguhan.

## File
- `index.html` — struktur halaman dan contoh konten
- `style.css` — layout responsif desktop, tablet, dan mobile
- `script.js` — ticker, pencarian, dark mode, navigasi mobile, carousel, newsletter demo, dan tombol kembali ke atas

## Menjalankan
1. Ekstrak ZIP.
2. Buka folder di VS Code.
3. Jalankan `index.html` dengan Live Server atau buka langsung di browser.

## Catatan
- Foto memakai URL Unsplash dan Google Fonts membutuhkan koneksi internet.
- Berita, tanggal acara, angka trending, dan iklan adalah konten contoh.
- Form newsletter hanya simulasi front-end; belum menyimpan email ke server.
- Ganti gambar, konten, logo, dan link dengan aset milik Anda sebelum publikasi.
